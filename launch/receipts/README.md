# Reviewed public orientation receipts

This directory contains only deliberately selected, sanitized public-practice receipts. Raw event streams, official recordings, anonymous keys, server-issued identifiers, environment variables, and private or competition material remain outside Git.

A receipt may establish bounded contact, configuration, action counts, state transitions, and an official terminal response for its named session. It does not prove general capability, independent replication, competition eligibility, or authorization for another run.

The first chat-mode orientation set is prepared locally for review under `2026-09-03-chat-mode-sol56/`. If that directory is absent on this branch, publication of the sanitized local receipt set remains pending rather than lost.
