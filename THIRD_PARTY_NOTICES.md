# Third-party boundary

No third-party source code, notebook, benchmark task/data row, task prompt,
evaluator test, model response, package artifact, or dataset file is copied
into this branch at preparation time. Selected public leaderboard fields are
recorded separately as attributed metadata observations.

The recorded public surfaces have distinct terms that must not be collapsed:

- `Kaggle/kaggle-benchmarks` carries Apache License 2.0.
- Kaggle dataset version 1 for
  `namanbnsl/rosettabench-150-stratified-compressed` reports MIT.
- The Hugging Face mirror reports only the ambiguous tag `license:cc`.
- The pinned `namanbnsl/RosettaBench` GitHub tree has no LICENSE, COPYING, or
  NOTICE file. Its reuse license is therefore unresolved.
- Kaggle's Rosetta writeup and individual task pages are separate publication
  surfaces with their own displayed licenses; they do not license the GitHub
  repository or every dataset mirror by implication.

Until those boundaries are reconciled for a particular use, inspect by link and
commit identity only. Do not vendor, modify, redistribute, or silently relicense
RosettaBench material. Fetched caches, if separately authorized later, remain
ignored and retain their upstream notices.

Original material in this title branch follows the repository's CC BY 4.0
license unless a file says otherwise. Christopher D. Pang directs and authors
the project. AI systems are development tools, not co-authors or independent
scientific authorities.
