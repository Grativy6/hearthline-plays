# Third-party source boundary

No third-party source code, competition data, model weights, or Kaggle artifact
is copied into this branch at preparation time.

The station records two public upstream repositories in
`source-lock.v1.json`:

- `royerlab/kaggle-cell-tracking-competition`, BSD 3-Clause;
- `royerlab/tracksdata`, BSD 3-Clause.

If either source is fetched later, its exact pinned commit and original license
must remain attached. A source fetch is not adoption, execution, benchmark
reproduction, or permission to enter the competition.

The repository's existing CC BY 4.0 license remains the default for original
branch material unless a file says otherwise. The competition's winner-code
MIT requirement is a later owner-controlled release gate; this preparation
branch does not silently relicense any work.
